# Описание для портфолио (Kwork / FL.ru)

## Название работы

Telegram-бот онлайн-записи для барбершопа / салона красоты

## Короткое описание (1–2 строки, для превью)

Бот, через который клиенты сами записываются на услуги 24/7, а мастер получает уведомления и управляет расписанием прямо в Telegram. Без сайта и без администратора на телефоне.

## Полное описание

Сделал Telegram-бота для онлайн-записи клиентов в барбершоп. Подходит для салона красоты, маникюра, массажа и любых услуг по записи.

**Для клиента:**
- запись в 4 нажатия: услуга → дата → время → подтверждение;
- показывается только реально свободное время с учётом длительности услуги, занятого и прошедшего времени;
- «Мои записи» с отменой в два нажатия;
- автоматические напоминания за сутки и за 2 часа до визита;
- прайс-лист с ценами и длительностью.

**Для мастера:**
- мгновенные уведомления о новых записях и отменах;
- расписание на любой день и сумма выручки за день;
- выходные и перерывы закрываются в пару нажатий;
- можно отменить запись клиента, бот сам его уведомит.

**Техническая часть:**
- Python 3.12, aiogram 3, SQLite, Pydantic — вся проверка данных в одном месте;
- защита от двойной записи: двое клиентов не займут одно время, даже если нажмут одновременно;
- напоминания не теряются и не дублируются после перезапуска;
- настройки (часы работы, шаг записи, часовой пояс, время напоминаний) меняются в файле конфигурации без правки кода;
- 67 автотестов на pytest: полные сценарии записи, отмены и админки, проверка данных;
- готов к запуску на сервере 24/7 (systemd или Docker), есть инструкция.

Демо: @bytecodebarberbot

## Что могу доработать под заказчика

- несколько мастеров со своим расписанием;
- запрос телефона клиента и выгрузка записей в Google Таблицы;
- предоплата через Telegram;
- управление услугами и ценами из админ-панели;
- рассылка акций по базе клиентов.

## Теги

Telegram-бот, aiogram, Python, бот для записи, онлайн-запись, барбершоп, салон красоты, SQLite, автоматизация бизнеса

## Скриншоты, которые стоит приложить

1. Приветствие с главным меню.
2. Выбор услуги с ценами.
3. Выбор даты и времени.
4. Подтверждение «Вы записаны!».
5. Напоминание с кнопкой отмены.
6. Уведомление мастеру о новой записи.
7. Админ-панель: расписание на день с выручкой.
8. Закрытие времени (выходной / перерыв).

Лучше всего работает короткое видео на 30–60 секунд, где показан весь путь клиента и уведомление мастеру.
